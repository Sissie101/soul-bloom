# 🌸 Soul Bloom

A wellness app built to support emotional growth, 
self-reflection, and daily inner care.

## What It Does
Soul Bloom guides users through mindfulness practices, 
emotional check-ins, and personal growth tools — 
designed for people who want more than a mood tracker.

## Built With
- React + Vite
- Tailwind CSS
- JavaScript / TypeScript
- Base44 Platform

## About The Developer
Self-taught developer and wellness creator building 
AI-powered tools for emotional wellbeing.
